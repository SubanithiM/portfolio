SUBANITHI M - PORTFOLIO (all in one)

Run:      extract this zip, then double-click index.html inside the extracted folder (do not open it from inside the zip).
Files:    index.html (content), style.css (design), script.js (animation, navbar, smoke, video button)
          about-reel.mp4 + about-poster.jpg (About section video and its first frame)
          Subanithi_M_Resume.pdf (View / Download Resume), profile.jpg (spare still photo, not used by the page)
Video:    to use a new About video, save it as about-reel.mp4 in this folder (same name, replace the old one).
          about-poster.jpg is only the picture shown before Play; keep it if the new video starts with the same photo.
          The video's own voice plays when the round button is pressed. Browsers do not allow sound to start by itself.
Deploy:   upload every file in this folder to GitHub Pages or Netlify (drag the folder onto app.netlify.com/drop).
